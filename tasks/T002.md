# T002 — Local repository hygiene

## Goal
Initialize the local Git repository and create ignore/environment templates for the Phase 0 skeleton. Do not implement application behavior.

## Files and operations
- Create `.gitignore` and `.env.example` only.
- Initialize local Git if absent. Do not add a remote, commit, push, or alter existing files.

## References
Read `README.md` environment requirements, `docs/architecture.md`, `docs/rules-checklist.md`, and `docs/responsible-ai.md`.

## Constraints
Synthetic data only; no secrets. Placeholders only in `.env.example`. Ignore `.env` and local env variants while retaining `.env.example`; ignore Python caches/venvs, Node dependencies/build outputs, macOS metadata and generated reports/model/data outputs where appropriate. Do not ignore source `data/config.yaml` or `docs/schema.sql`. No installs, generators, models, policy logic, UI, deployment or remote operations. Do not change design decisions. Codex performs final review and commit.

## Acceptance criteria
Local Git exists. `.env` is ignored and `.env.example` is trackable. The template documents DATABASE_URL, JWT_SECRET, optional LLM_API_KEY/STT_API_KEY, and SATHI_CONFIG with placeholders. Existing source docs remain trackable.

## Exact checks
```
git status --short
git check-ignore .env
git check-ignore --no-index .env.example data/config.yaml docs/schema.sql
git diff --check
```
The third command must return exit 1 with no matches (none of those source files should be ignored). Explain this expected exit status. Report all changed files and commands/results. Do not commit or push.
